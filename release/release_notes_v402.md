# Skinner v4.0.2 — Minimal Flat Theme, Studio Context Actions, Clean Modals & Focused Layouts

### 🌟 What's New & Fixed in v4.0.2:

1. **Restored Dedicated Three-Dots Action Menu (استعادة زر النقاط الثلاث ... لخيارات الخانة):**
   - Restored the standalone `...` slot menu button beside the preset dropdown in the Legend Customizer studio.
   - Houses quick contextual actions: **Rename Slot (إعادة تسمية الخانة)**, **Duplicate Slot (نسخ هذا التعديل)**, **Reset to Default (إعادة تعيين الخانة للافتراضي)**, and **Delete Slot (حذف الخانة)**.
   - The dropdown itself now strictly focuses on instant preset switching and adding new slots.

2. **Polished In-App Rename Modal (نافذة إعادة التسمية بحلتها النظيفة والمثالية):**
   - Removed the top-right `✕` close button for a cleaner, modern dialogue experience.
   - Removed the edit pencil icon from the title header.
   - Added balanced spacing (`gap: 16px`) between the action buttons (**حفظ التسمية** and **إلغاء**).

3. **Borderless Settings Close Button (إزالة الإطار المحيط بزر الإغلاق في الإعدادات):**
   - Removed the default square button outline/perimeter around the `✕` close button in the Settings window.
   - Clean, borderless minimalist icon button with gentle hover transitions.

4. **Minimal Flat Sidebar Navigation (شريط جانبي أنيق بخط تمييز جانبي فقط):**
   - Removed icons and icon badges beside section names ("الأساطير", "تأثيرات الإطاحة", "سكنات الأسلحة").
   - Removed the blue pill background fills on active and hover states.
   - Applied a sleek, crisp accent indicator line on the left side (`border-left: 3px solid #3b82f6`) for an ultra-clean appearance.

5. **Streamlined KO Effects View (إزالة قائمة تصفية تأثيرات الإطاحة غير المفيدة):**
   - Removed the category dropdown from the KO Effects page header as requested.
   - The search bar now spans the full header area cleanly, providing instant filtering across all 49 knockout effects.

6. **Perfect Horizontal Alignment for Auto-Repair (محاذاة زر فحص وإصلاح الآن بدقة):**
   - Centered the "فحص وإصلاح الآن (Auto-Repair)" button vertically with sibling controls in the Maintenance & Recovery tab.

7. **Completely Removed Glow Halos (إلغاء تأثير التوهج Glow بالكامل):**
   - Replaced radial gradient lighting backgrounds in the main viewport with a clean, flat, high-contrast dark theme (`#121316`).
   - Removed blurred outer box-shadow glows from primary buttons, cards, and interactive pickers for a razor-sharp, distraction-free interface.

8. **Cryptographic Ed25519 Signing & Checksums:**
   - All update artifacts signed with the official Ed25519 private key and verified with SHA-256 manifests.
