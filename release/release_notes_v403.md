# Skinner v4.0.3 — Weapon Skins Unlocked, Dedicated Notifications Settings & Refined UI

### 🌟 What's New & Enhanced in v4.0.3:

1. **Unlocked Weapon Skins Tab (فك القفل عن تبويب سكنات الأسلحة):**
   - Completely unlocked the **Weapon Skins (سكنات الأسلحة)** navigation tab in the sidebar.
   - Integrated keep-alive DOM mounted rendering for instant, zero-delay switching.
   - Connected full customizer workflows with dynamic weapon type filtering, gallery previews, color scheme swaps, and game launch controls.

2. **New Dedicated Notifications Tab in Settings (تبويب جديد للإشعارات في الإعدادات):**
   - Added a new **Notifications (الإشعارات)** tab in Settings with a crisp toggle switch.
   - Allows users to easily enable or disable in-app toast alerts, success banners, and action feedback according to their preference.
   - Preference persists across sessions in local storage.

3. **In-App Test Alert Verification (زر تجربة الإشعارات):**
   - Added a test trigger button in the Notifications settings to preview how popup alerts look at the bottom of the screen.

4. **Dedicated Update Icon (أيقونة مخصصة لتحديثات البرنامج):**
   - Replaced the bell icon on the **Software Updates (التحديثات)** tab with the universal circular refresh/update arrows icon.
   - Dedicated the classic bell icon specifically to the new Notifications tab for intuitive navigation.

5. **Cryptographic Ed25519 Signing & Checksums:**
   - All update artifacts signed with the official Ed25519 private key and verified with SHA-256 manifests.
